# Hi, I'm a Statistics & Data Science Graduate 👋

I'm a Statistics and Data Science graduate from the University of Bath, with an academic background in Economics and Management from the University of London.

I'm interested in using data to solve practical problems, uncover insights and support data-driven decision-making. My interests include data analysis, statistical modelling, machine learning and data visualisation.

### Technical Skills
- **Programming:** Python, R, SQL
- **Data Analysis:** Pandas, NumPy, Tidyverse
- **Visualisation:** Matplotlib, Seaborn, Tableau, ggplot2
- **Tools:** RStudio, Jupyter Notebook, GitHub, Excel

### Projects
This GitHub profile showcases selected academic and independent projects involving:
- Exploratory data analysis and data visualisation
- Statistical modelling and hypothesis testing
- Machine learning and predictive analysis
- Experimental design and spatial data analysis

I'm continuously developing my technical skills and expanding my portfolio through practical data projects.

Thanks for visiting!
